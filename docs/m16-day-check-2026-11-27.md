## 5. Full-list validation (the update runs clean)

A disk replay of the merged code over the whole **210-name core universe** for
27-Nov, plus the five extra names that have history:

- **353 s** for 210 symbols×75 bars, no exception, no missing-history diagnostic.
- **143 seeds** — exactly the 143 original tracked signals of the live session, so
  the replay reproduces the day's seeding deterministically.
- 37 continuation events (23 `CLOSE_ONLY`, 14 `DIRECT_BOS_CONFIRMED`); replay
  cannot see intrabar crossings, so it never emits `RUNNING_BREAK`, which is why
  the live session recorded 58 events with 24 running breaks.
- The five extra names produce **5 setups / 2 confirmations**, as in §3.

## 6. Caveats

- Replay collapses every observation to one wall-clock moment, so the replay cannot
  claim a delivery time; the *live* code stamps the real observation time and
  applies the 30 s freshness and 15-minute late windows unchanged.
- 191 of the 196 new names have no local history, so their 27-Nov results are
  unknown offline. Any claim about them would be invented.
- Nothing here is a P&L: M16 is alerts-only, no fills, no costs, no stops.
